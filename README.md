# 🌟 Tactile Skeuomorphic Web Store & Visual Tree Directory

🌐 **Live Demo**: [https://shariar-ahamed.github.io/web-site-store/](https://shariar-ahamed.github.io/web-site-store/)

A handcrafted, tactile **Skeuomorphic UI** (Day/Light Mode) web store and hierarchical directory designed to easily navigate, organize, and search your curated bookmarks and developer websites.

Pre-configured directly with the category structure and bookmarks from Google Chrome's **"⭐ All Websites"** folder.

---

## ✨ Features

- **Tactile Skeuomorphism (Light / Day Mode)**:
  - Studio drafting surface texture with realistic directional illumination.
  - Convex push-buttons with real press-down depth (`transform: translateY(1.5px)` with inset shadow).
  - Recessed search tray with engraved shortcut tag (`Ctrl + K`).
  - Embossed and engraved typography (Plus Jakarta Sans).
  - Zero generic AI feel — looks and feels like a tangible workstation binder.

- **🗂️ 3 Switchable View Modes**:
  - **🗂️ Desk Grid** *(Default)*: Tactile skeuomorphic physical cards & folder tabs.
  - **🌳 Tree View**: Vertical directory tree with connecting branch connectors (`├──`).
  - **🔗 Chart View**: Horizontal branching node mind map with smooth cubic bezier curves, pan & zoom canvas, and collapsible branches.

- **Protected & Curated Directory**:
  - Pre-loaded with all **87 folders** and curated bookmarks (OSINT, Dev, AI, Design, Learn, Tools, Projects, More).
  - Clean, fixed database structure so visitors cannot tamper with or reset your curated links.

## 🚀 How to Run Locally

```bash

```
Then open `http://localhost:3000` in your browser.
